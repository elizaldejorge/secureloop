Roles & Access

Four-tier RBAC. Master PIN logs you in as Admin. Admins issue scoped tokens for lower roles — share a token instead of the PIN. Tokens are time-bound and shown once.

RoleCapabilities
Admin Manage PIN, mint/revoke role tokens, edit policy, manage block/whitelist, apply autofix.
Operator Run scans, propose patches, apply approved autofixes. Cannot manage roles or change policy.
Auditor Read everything, run scans, export reports (CSV / JSON / SARIF / HTML). No fix application.
Viewer Read-only: scans, findings, patches, audit log, reports. Cannot trigger any action.

Issue a delegated token

Notifications & Webhooks

Fire a webhook (Slack, Teams, or generic JSON) when a scan produces findings at or above your chosen severity. Local-first — no Anthropic/OpenAI proxy involved.

Disabled by default. Off-by-default for offline use.

AI Provider

The deterministic Brain runs every scan. The LLM only adds polish on top — never silent fixes. Configure a remote model (OpenAI) or a fully-local model (Ollama). Local-only is the default.

Data Retention & Export

All scan history, audit log entries, and patches live in db/secureloop.db. Adjust day-based retention in Policy → retention.*. Export everything for offline backup or external SIEM ingest.
